# İsim Önerileri

Seçtiğin adı Claude Code'a söyle: "Uygulamanın adı X olsun" yeterli, CLAUDE.md'deki kurala göre
gerekli yerleri günceller.

| Ad | Neden |
|---|---|
| **Çözüm Defteri** (şu anki geçici ad) | Ne olduğunu direkt söyler, sade |
| Arıza Defteri | IT'de alışılmış "arıza defteri" kavramı |
| Çözdüm | Kısa, akılda kalır, simge altında iyi durur |
| Tekrar | "Bu yine oldu" fikrine gönderme |
| Petka Destek | Şirket adıyla, ekibe açılırsa uygun |
| İzNot | "Bıraktığın iz" + not, kısa |
